## 实现方式

1. 调 B站公开热门榜 API：

```text
https://api.bilibili.com/x/web-interface/popular?ps=20&pn=1
```

2. 过滤：

```text
时长 <45 秒或 >30 分钟
标题含：广告 / 直播 / 预告 / 付费 / 大会员 / 充电专属
```

3. 用深链打开真实视频：

```text
bilibili://video/{bvid}
```

4. 播放 25–80 秒（按时长比例，最多 80 秒）

5. 取视频信息：

```text
x/web-interface/view?bvid=...
```

- 标题
- UP 主
- 简介
- cid / aid
- 播放量

6. 尝试取字幕：

```text
x/player/v2?bvid=...&cid=...
```

有字幕就取前 1200 字。

7. 取热门评论（最多 3 条，每条 100 字）

8. 清洗广告/促销：

```text
万宝楼 / 会员购 / 优惠 / 折扣 / 券 / 广告 / 联名 /
预约 / 下单 / 购买 / 淘宝 / 京东 / 上新 / 福利 / 充值
```

9. 用 Fast Chat 生成 1–2 句“看懂”：

- 不复述标题
- 不编造没出现的情节
- 忽略广告和促销
- 120 max tokens，thinking 关闭

10. 写入日记：

```text
刷B站：标题（BV号）
看懂：...
```

11. 结束后远程推送一条总结，含最后看懂的内容。

## 边界

- 不点赞
- 不评论
- 不投币
- 不充电
- 不购买/会员购
- 不看付费内容
- 不碰评论输入框

## 已知限制

- 现在用热门榜，不是登录后的个性化推荐
- 个性化需要把 B站登录 cookie 接进来
- 播放需要亮屏；原来熄屏会自己点亮，刷完再熄屏
- 没有字幕的视频只能靠标题/简介/评论理解，可能不够准
- 长视频只取前 25–80 秒，不会真的看完 20 分钟
