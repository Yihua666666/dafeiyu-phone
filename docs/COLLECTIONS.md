## 目录

```text
/sdcard/DeepSeekGirl/collections/

  images/              B站封面 / 评论图
```

每条记录：

```json
{"ts":1793500000000,"type":"评论梗","text":"...","source":"B站评论：标题"}
{"ts":1793500000000,"type":"表情包","image":"/sdcard/.../images/bili_xxx.jpg","source":"B站评论图：标题"}
```

## B站

在 `biliUnderstand()` 里判断，如果她的理解包含：

```text
好笑 / 笑死 / 梗 / 吐槽 / 离谱 / 名场面 / 可爱 / 有趣 / 搞笑 / 整活
```

就收藏：

- 她自己的吐槽（type=她的吐槽）
- 第一条热门评论（type=评论梗）
- 视频封面（type=封面）
- 评论区图片（type=表情包，最多 2 张）

会过滤广告、促销、会员购、万宝楼等。

## QQ

`im_watch.js` 收到消息时，如果正文包含：

```text
笑死 / 哈哈 / hhh / 梗 / 离谱 / 绷不住 / 破防 / 乐子 / 草 / 典 / 急了 / 表情包
```

就把文字收进 `memes.jsonl`，type=`QQ梗`。

## 手动收藏

远程聊天发：

```text
收藏 这个梗的内容
记梗 这个梗的内容
```

## 限制

- QQ 的**图片/表情包**拿不到：通知里只有 `[图片]`/`[表情]`，QQ 不把文件给通知监听器。
- B站评论图/封面可以下载；视频画面里的表情包不能直接抓，除非截屏。
- 所有收藏只存手机本地，不自动发到群里，不推 GitHub。
- 收藏是个人使用，注意版权和来源标注。
