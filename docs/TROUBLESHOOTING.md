# 常见问题

| 现象 | 原因/处理 |
|---|---|
| 悬浮窗点不到 | 面板可能被状态栏/投屏挡住；用桌面“大肥鱼”App 作为备用入口；收起后面板有“看看她在不在”大按钮 |
| 面板消失 | 脚本停了或被系统杀了；AutoX → 管理 → 重新运行 `agent.js`；检查前台服务 |
| 一直回“正在做事” | 任务卡住；发 `/stop`；超过 2 分钟无进展会自动停 |
| 写文件报 `ENOENT` | 父目录不存在；新版会自动建父目录 |
| 查存储被安全中心拦 | 不要打开存储清理页；让她用 `storage_info` |
| 没 Wi-Fi 还发消息 | Agent 只在 Wi-Fi 下工作，避免走 SIM |
| LLM HTTP 401 | API Key 错，重新设置 |
| LLM HTTP 404 | Base URL 少 `/v1`，或模型名错 |
| LLM 返回空内容 | 模型偶发；等下一轮，或换模型 |
| App“连接失败” | topic 错、ntfy 不通、Wi-Fi 断；看 `/sdcard/PhoneAgent/events.log` |
| App 429 | ntfy 限流；等 60 秒，不要连续刷 |
| 重启后她没回来 | 优先检查 `DafeiyuBoot`：自启动、悬浮窗、通知、后台弹出界面；在启动器里点“测试开机服务” |
| 启动器测试能起，开机不起 | 系统跳过了 BOOT_COMPLETED：打开启动器的“自启动”；部分 ROM 还要“后台弹出界面” |
| 开机后只有启动日志，没有面板 | AutoX 的无 UI 后台上下文会挂起脚本；用 `DafeiyuBoot` 的 ShortcutActivity 方式，不要只靠 `setup_boot.js` |
| 启动器留了“大肥鱼还没起来”通知 | 系统拦了后台启动；点通知手动启动，或去系统里允许“后台弹出界面” |
| 无障碍服务自动关闭 | Android 13+ 侧载限制/系统清理；在应用信息里允许受限制设置，重开自动启动 |
